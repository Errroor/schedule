# Расписание PWA

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этой папки:
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - apple-touch-icon.png
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch.
5. Выберите ветку main и папку /(root), затем Save.
6. Откройте выданную GitHub Pages ссылку на Android хотя бы один раз с интернетом.
7. В Chrome нажмите «Установить приложение» на странице или меню ⋮ → «Добавить на главный экран» / «Установить приложение».

После первого успешного открытия приложение сохраняет основные файлы и работает без интернета.
При наличии интернета страница загружает свежую версию.

Важно: Service Worker работает на GitHub Pages (HTTPS), но обычно не работает при простом открытии index.html через файловый менеджер.
